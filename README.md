<h1 align="center">لغة باء</h1>

<p align="center">
  لغة برمجة نظم ذات صياغة عربية، تنتج برامج أصلية لويندوز ولينكس.
</p>

<p align="center">
  <code>الإصدار 0.6.0</code> · <code>ويندوز x86-64</code> · <code>لينكس x86-64</code>
</p>

باء لغة ومُصرِّف عربيان لبناء برامج أصلية. يملك المُصرِّف المرجعي المكتوب بلغة C تعريف الصياغة والتحليل الدلالي والتشخيصات والنظام الوسيط وتوليد مصدر [نظم](https://github.com/OmarAglan/Nazm). يستخدم مسار الإنتاج مجمّع نظم افتراضياً، ولا يرجع بصمت إلى مجمّع آخر عند الفشل.

## مثال سريع

احفظ الملف الآتي باسم `مرحبا.باء` بترميز UTF-8:

```baa
صحيح الرئيسية() {
    اطبع "مرحباً بالعالم!".
    إرجع ٠.
}
```

ثم صرّفه وشغّله:

```powershell
.\build\baa.exe .\مرحبا.باء -o .\مرحبا.exe
.\مرحبا.exe
```

```sh
./build-linux/baa ./مرحبا.باء -o ./مرحبا
./مرحبا
```

## ما الذي توفره باء؟

- كلمات مفتاحية وأعداد وعلامات ترقيم عربية في مصدر البرنامج.
- تصريف أصلي إلى PE/COFF على ويندوز وELF على لينكس لمعمارية x86-64.
- أنواع صحيحة وعشرية، مؤشرات، مصفوفات، نصوص، هياكل، اتحادات، تعدادات، ومؤشرات دوال.
- نظام وسيط داخلي، تحسينات متعددة المستويات، وفحوص IR وSSA.
- مكتبة قياسية تشمل النصوص، الذاكرة، الملفات، العمليات المهيكلة، والحاويات الأساسية.
- تشخيصات عربية ذات رموز ثابتة ونطاقات مصدر دقيقة.
- عقود JSON مستقرة للتشخيصات والرموز والتلوين والإكمال والتنسيق والبنية والأدوات المحيطة.
- بناء متعدد الملفات، مسارات تضمين، أهداف متعددة، وكاش تزايدي اختياري.

التفاصيل الدقيقة للصياغة والسلوك موجودة في [مواصفة اللغة](docs/LANGUAGE.md)، أما القيود المؤكدة فموجودة في [القيود المعروفة](docs/KNOWN_LIMITATIONS.md).

## التثبيت على ويندوز

ثبّت [نظم](https://github.com/OmarAglan/Nazm) أولاً، ثم شغّل
`baa-setup-0.6.0-x64.exe`. يثبت مُثبّت باء المستقل `baa.exe` والمكتبة
القياسية ورابطاً خاصاً داخل مجلد باء، ويضيف باء وحده إلى `PATH`. لا يضيف
GCC الخاص إلى `PATH` ولا يعتمد على GCC مثبت في النظام؛ يجد مجمّع `نظم`
المستقل من `PATH`. إذا لم يجده، يتوقف باء بتشخيص واضح ورمز فشل سلسلة
الأدوات `4` ولا ينتج ملفاً ناقصاً أو يرجع إلى GAS بصمت.

التثبيت الافتراضي لكل مستخدمي الجهاز داخل `Program Files\Baa`. يدعم
المثبت `/CURRENTUSER` للتثبيت دون صلاحيات مدير، كما يدعم الأوضاع الصامتة
القياسية لـ Inno Setup. بعد التثبيت افتح طرفية جديدة وتحقق:

```powershell
نظم --إصدار
baa --version
```

لبناء المثبت من المصدر:

```powershell
.\scripts\prepare_gcc_bundle.ps1
.\scripts\build_installer.ps1 -NazmExecutable C:\path\to\نظم.exe
.\scripts\test_installer.ps1 -NazmDirectory C:\path\to\nazm-bin
```

لبناء إصدار Authenticode، مرر `-SignToolName releasesign` و
`-SignToolCommand '<signtool command using $f>'`. يوقع البناء المثبت وبرنامج
الإزالة قبل إنشاء ملف SHA-256 المجاور.

## البناء

### المتطلبات

- CMake 3.10 أو أحدث.
- مُصرِّف C يدعم C11: MinGW-w64 على ويندوز أو GCC/Clang على لينكس.
- مجمّع [نظم](https://github.com/OmarAglan/Nazm) عند تصريف برامج باء إلى ملفات كائن أو ملفات تنفيذية.
- Python 3 لتشغيل بوابات الجودة.

يمكن تحديد ملف نظم التنفيذي عبر `--nazm-path` أو متغير البيئة `BAA_NAZM`، وإلا يبحث باء عن الأمر `نظم` في `PATH`.

### ويندوز

```powershell
git clone https://github.com/OmarAglan/Baa.git
cd Baa
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build
.\build\baa.exe --version
```

### لينكس

```sh
git clone https://github.com/OmarAglan/Baa.git
cd Baa
cmake -S . -B build-linux -DCMAKE_BUILD_TYPE=Release
cmake --build build-linux --parallel
./build-linux/baa --version
```

توجد إعدادات إضافية جاهزة في [CMakePresets.json](CMakePresets.json)، كما توجد إرشادات المسارات وسلسلة الأدوات على ويندوز في [دليل سلسلة الأدوات](docs/WINDOWS_TOOLCHAIN_PATHS.md).

## أوامر أساسية

```text
baa <ملف.باء> -o <البرنامج>
baa --check <ملف.باء>
baa -S <ملف.باء>
baa --target=x86_64-windows <ملف.باء>
baa --target=x86_64-linux <ملف.باء>
baa --help
```

يعرض `baa --help` القائمة الكاملة والمحدّثة للخيارات. عند اختلاف الهدف عن نظام المضيف، يقتصر الدعم الحالي على توليد مصدر التجميع عبر `-S`؛ راجع [مصفوفة التوافق](docs/COMPATIBILITY_MATRIX.md) قبل الاعتماد على مسار عابر للأهداف.

## منظومة باء

- [نظم](https://github.com/OmarAglan/Nazm): المجمّع العربي ومسار الإنتاج الافتراضي.
- [تكوين](https://github.com/OmarAglan/Takween): نظام المشروعات والبناء والحزم.
- [Baa-LSP](https://github.com/OmarAglan/Baa-LSP): خادم بروتوكول خدمات اللغة دون واجهة رسومية.
- [قلم](https://github.com/OmarAglan/Qalam-IDE): بيئة التطوير المخصصة لباء.

يبقى باء مصدر الحقيقة للغة والتشخيصات والتنسيق والبنية الدلالية؛ لا تعيد الأدوات المحيطة تنفيذ قواعده في محللات مستقلة.

## التحقق والجودة

```powershell
python .\scripts\qa_run.py --mode quick
python .\scripts\qa_run.py --mode full
python .\scripts\qa_run.py --mode release
```
