# عقد ترحيل التجميع الضمني إلى نظم

## الحالة

كتلة `مجمع { ... }` الحالية تحمل نص GAS خاما وقيود سجلات لاتينية داخل مصدر
باء. هي ما تزال مدعومة في مسار GAS الإنتاجي للتوافق، لكنها ليست جزءا من عقد
نظم العربي ولا يجوز نسخ نصها أو تفسيره على أنه مصدر نظم.

عند وصول `MACH_INLINE_ASM` إلى `--emit-nazm` أو `--nazm-shadow` يفشل باء بحالة
`compiler-cli-v1` رقم `3` والعائق المستقر:

```text
ترحيل_التجميع_الضمني / مجمع_جاس_خام
```

لا يترك الفشل مصدر نظم جزئيا ولا يرجع بصمت إلى GAS.

## الواجهات المستهدفة

الإصدار الكاسر المستهدف يحذف `مجمع` والنص الخام، ويقسم الاستعمال إلى واجهتين.

### عمليات داخل دالة باء

العمليات الصغيرة التي تحتاج قيم باء تصبح builtins عربية مهيكلة، لا نصا
تجميعيا. الشريحة الأولى المطلوبة من corpus هي:

```baa
لا_تفعل().
ص٦٤ ختم = اقرأ_عداد_الزمن().
```

لا يكتب مستخدم باء `nop` أو `rdtsc` أو قيودا مثل `=a` و`=d`. تربط العملية
العربية نتيجتها بقيمة باء مباشرة، ويتحقق المحلل الدلالي من النوع. يخفض
المصرّف العملية إلى Machine IR واحد؛ مصدر GAS يكتبه بلهجته الحالية ومصدر نظم
يكتبه بالاسم العربي القانوني.

### وحدات نظم مستقلة

التجميع الأكبر أو المتخصص يكتب في ملف `.نظم` مستقل. يعامل Takween الملف
كمصدر أولي، يستدعي `nazm` من المسار المهيأ أو `PATH`، ثم يربط الكائن مع كائنات
باء. هذه هي النظيرة المباشرة لربط ملفات `.c` و`.s` في مشروع C، لكن بصياغة
عربية خالصة.

يضيف باء `--assembler=nazm` للمسار الطبيعي:

```text
باء → Machine IR → مصدر نظم عربي → nazm → كائن → الرابط
```

يبقى `--assembler=gas` رجوعا صريحا ومقاسا خلال الهجرة، ولا يحول فشل نظم إلى
نجاح.

كتلة `نظم { ... }` داخل دالة ليست مطلوبة لحل corpus الحالي. إن أضيفت لاحقا
فيجب أن تملك مدخلات ومخرجات وسجلات مهدومة صريحة وأن تعمل فقط عبر مسار نظم؛
لا تكون غلافا لنص حر، ولا تجعل باء يكرر محلل نظم أو يترجم النص إلى GAS.

## حدود الملكية

- واجهة باء الأمامية تملك builtins العمليات الصغيرة وتشخيصات النوع.
- Machine IR يملك عمليات آلة مهيكلة ومواضع المصدر؛ لا يحمل سطرا تجميعيا خاما.
- مصدر GAS الإنتاجي يخفض العملية المهيكلة إلى تعليمة الأداة الحالية داخليا.
- مصدر نظم يخفض العملية نفسها إلى الاسم العربي القانوني.
- Nazm يملك تحليل مصدر نظم، الترميز، وكتابة ELF64/COFF. لا تنسخ هذه الطبقات
  داخل باء.
- Takween يملك اكتشاف ملفات `.نظم`، بناء أوامر Nazm المنظمة، وربط الكائنات
  داخل DAG البناء.

## خطة التنفيذ

1. إضافة تعليمة Nazm العربية `اقرأ_عداد_الزمن` مع اختبار بايتات مستقل
   (`0F 31`) وfixture قبول ELF64/COFF.
2. إضافة عملية Machine IR مهيكلة لقراءة عداد الزمن وbuiltin باء يعيد `ص٦٤`؛
   لا تستخدم `comment` لحمل نص تعليمة أو قيود سجلات.
3. خفض العملية نفسها إلى GAS الإنتاجي ومصدر نظم غير الافتراضي من Machine IR.
4. إضافة `--assembler=nazm` الذي يحل المسار من الإعداد أو `PATH`، مع
   `--assembler=gas` رجوعا صريحا مؤقتا.
5. جعل Takween يجمع ملفات `.نظم` مباشرة ويضم كائناتها إلى خطة الربط.
6. ترحيل اختبار التكامل إلى builtin العربي، ثم حذف قبول `مجمع` برسالة ترحيل
   صريحة.
7. إعادة توليد مصفوفتَي المئة مصدر وتشغيل تكافؤ الكائن والربط والتشغيل على
   ويندوز ولينكس.

## شروط القبول

- لا يتطلب مصدر باء أي mnemonic أو قيد سجل لاتيني.
- لا يحتوي مصدر نظم المولد حرفا لاتينيا.
- ينتج GAS ونظم السلوك نفسه للعملية المهيكلة على الهدفين.
- تجمع مشروعات Takween ملفات `.باء` و`.نظم` في خطة واحدة حتمية.
- يبقى كل شكل غير مدعوم فشلا عربيا ظاهرا بلا نص خام أو رجوع صامت.
